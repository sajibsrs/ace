# Language Philosophy

## General Goals
1. As simple/minimal as it goes.
2. Don't force thing that can be optional.
3. Performance is the ultimate goal.
4. Simple, clean, distinguishable and pragmatic syntax.
5. True to machine (less magic).

## Parsing
1. Single lookahead parsing LL(1) with little or no backtracking.
2. Recursive descent top-down parsing implementation.
